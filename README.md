# AI-Driven-Research-Methodology
Hands-on materials for AI-Driven Research Methodology

## Contents

The notebook covers:

- OpenAI API basics
- Prompting and parameter control
- Embeddings
- Semantic retrieval
- In-memory RAG
- Vector Stores
- File Search

## How to Use

1. Open the Colab notebook.
2. Make a copy in your Google Drive.
3. Add your OpenAI API key to Colab Secrets.
4. Upload the five PDF papers provided during the seminar.
5. Run the cells in order.

## Important

Do not enter your API key directly into the notebook.
Store it securely in Google Colab Secrets as:

`OPENAI_API_KEY`
